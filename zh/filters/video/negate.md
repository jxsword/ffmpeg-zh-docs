# negate

Negate (invert) the input video.

It accepts the following option:

- **`components`** Set components to negate.

  Available values for components are:

  - **`y`**

  - **`u`**

  - **`v`**

  - **`a`**

  - **`r`**

  - **`g`**

  - **`b`**

- **`negate_alpha`** With value 1, it negates the alpha component, if present. Default value is 0.

## Commands

This filter supports same [commands](#commands) as options.
