# lagfun

Slowly update darker pixels.

This filter makes short flashes of light appear longer. This filter accepts the following options:

| Term | Description |
|----|----|
| `decay` | Set factor for decaying. Default is .95. Allowed range is from 0 to 1. |
| `planes` | Set which planes to filter. Default is all. Allowed range is from 0 to 15. |

## Commands

This filter supports the all above options as [commands](#commands).
