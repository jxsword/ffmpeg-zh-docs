# 描述

libavdevice 库提供从多种常见多媒体输入/输出设备进行抓取以及向其渲染输出的通用框架，并支持多种输入和输出设备，包括 Video4Linux2、VfW、DShow 和 ALSA。

# 另请参见

ffmpeg(1), ffplay(1), ffprobe(1), ffmpeg-devices(1), libavutil(3), libavcodec(3), libavformat(3)
