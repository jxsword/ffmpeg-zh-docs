# 描述

libavcodec 库提供通用的编码/解码框架，包含面向音频、视频和字幕流的多个解码器与编码器，以及若干比特流滤镜。

这一共享架构提供从比特流 I/O 到 DSP 优化的各类服务，使其既适合实现健壮而快速的编解码器，也适合进行实验。
