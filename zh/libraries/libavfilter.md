# 描述

libavfilter 库提供通用的音频/视频滤镜处理框架，其中包含多个滤镜、源和汇。

# 另请参见

ffmpeg(1), ffplay(1), ffprobe(1), ffmpeg-filters(1), libavutil(3), libswscale(3), libswresample(3), libavcodec(3), libavformat(3), libavdevice(3)

有关作者身份的详情，请参阅项目的 Git 历史 (https://git.ffmpeg.org/ffmpeg)，例如在 FFmpeg 源码目录中键入 `git log` 命令，或浏览 <https://git.ffmpeg.org/ffmpeg> 上的在线仓库。

各具体组件的维护者列表见源码树中的 `MAINTAINERS` 文件。
