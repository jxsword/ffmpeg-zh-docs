# 描述

libavformat 库提供用于对音频、视频和字幕流进行复用与解复用（muxing 与 demuxing）的通用框架。它涵盖面向多媒体容器格式的多种复用器和解复用器。

它还支持多种输入和输出协议以访问媒体资源。
