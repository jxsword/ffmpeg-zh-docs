## 3. 新坑位与经验（重要，避免重踩）

1. **机械段生成器是超大文件的最优解**（本批最大方法论沉淀，F 系列强烈建议沿用）：drawvg 929 每段分类中 438 段为纯机械段——div 标记逐字、"Example"→示例、签名行（**两种空格形态**：3 空格破折号与不间断空格破折号并存于同一文件，正则须同时覆盖，本次第一版漏 5 条靠断言抓出）、纯链接列表项、命令名标题逐字、"Like X but relative"句式、"See the documentation of cairo 函数"句式、"See the X section above"句式（链接文本需小映射表，**译文不得引入源文没有的内联码**）。生成器+断言（目标全覆盖/无重复索引/改写计数==源文链接计数）一次产出 17 文件；散文段 401 段手写。滤镜页（Options/Examples/签名行高度重复）直接适用。
2. **译文中不得新增源文没有的链接**：drawvg [900]/[916] 源文为斜体纯文本，初稿误加链接——锚点改写脚本的"改写计数==源文链接计数"断言抓出（28 vs 30）。**链接计数逐段比对应列为三重检查常规项**。
3. **机械模板不得引入源文没有的内联码**：drawvg [725] 链接文本 "Command print" 被模板写成带反引号形态——内联码多重集检查抓出。
4. **锚点映射表要点**（81 目标 → 66 slug）：合并标题（clip/eoclip 等 10 组）全部别名指向同一 slug；**Q/q 标题 slug 撞车**（均 slug "q"，mkdocs 去重后第二个为 q_1）→ 两锚点均指首现 slug q（fix_links 规则 1 索引无去重后缀，语义落点为相邻小节，**规避 anchor_map 缺陷数据回写 #section**）；概念锚点（current-point/fill-rules/transformation-matrix 等 texi 中无对应标题）指向语义落点小节（当前点/填充/变换），经上下文确认；译文标题中的内联码保留内联码、仅译外围散文。
5. **裸 URL 后接中文句号会粘连**：nut [3] 段——URL 吸附后文。对策：裸 URL 改写为 markdown 链接（mailing-list-faq 惯例），代价是校验器 URL 计数 warning（源 0/目标 1，已甄别为误报）；若 URL 后有空格则可保留裸 URL（community vote.ffmpeg.org 形态）。
6. **"一节→小节"是 B9 唯一真偏差**（B6 §3.2 判据实操）：drawvg 手册节引用 "section X in ffmpeg-utils" 初译"一节"，glossary section=小节（B2 定稿）——21 处随批回改。本批甄别记录（全部误报）：segment←line segment（线段）、program←programming 子串、wrapper←convenience wrapper（fate 测试包装器 vs 命令便捷封装）、URL count mismatch（裸 URL 链接化改进）、duration/bitrate/resolution/input/pin（community 五条：任期 vs 时长/arbitrate 子串/解决流程/征求意见/opinions-helping 子串）、flag（nut，主头字段名 flags 不译）。
