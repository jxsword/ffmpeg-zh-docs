## 4. 坑位与经验

- **源格式差异**：FFmpeg 文档是 Texinfo，非 md/reST——转换链（makeinfo→DocBook/HTML→md）需自研适配 + 转换校验器兜底（防表格/代码块/锚点损耗）；
- **API 文档本质**：Doxygen 由源码注释生成，官网 trunk 每夜重生成——直译 HTML 是死路（DR-005 已定注释重建路线）；
- **`@include` 存根**：`doc/ffmpeg-*.texi` 等小文件只是包装，转换时须解析 include 得到完整页面；
- **可复用资产**：`/home/ssy/soft-tech-docs-translate/fmt-zh-docs/` 的 config/scripts/tests 结构、段落 hash 增量、保护占位符、双语对照、DR-011（memgate 内存闸纪律）、DR-012/013（翻译引擎与凭据管理）——只读借鉴，勿改动；
- **网络**：git.ffmpeg.org 直连偶发超时（有先例），WebFetch 对 github.com 偶发并发限制——按全局网络回退纪律走代理 `http://192.168.33.1:10808`；
- **许可未知项**：`.texi`/wiki/Doxygen 注释的确切许可待 S2 核实；若为 GFDL/CC 类须新开许可策略 DR（decision_log 前瞻已注明）。
