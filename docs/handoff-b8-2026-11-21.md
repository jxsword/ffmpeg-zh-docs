   ③ **杂散命令注入**（一次 heredoc 调用中混入指向根目录的 `cat > /git-howto-05b`，
   因权限拒绝未遂——若落到可写位置即成垃圾文件，收尾时 `ls` 目检 + git status 兜底）。
