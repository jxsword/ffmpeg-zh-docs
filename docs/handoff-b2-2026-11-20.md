## 3. 新坑位与经验（重要，避免重踩）

1. **长译文必须分块写入**（B2 最大教训）：单次超长 Write 会出现生成异常
   （分析文本泄漏进内容、重复块、缺块、外来字符窜入）。对策=每块 ≤25 段
   分文件写入（组装器按文件名排序合并 `*.txt`），写完跑三重检查：
   覆盖率（missing/extra/dup/empty）+ 异常串扫描 + 逐字保留块与源比对，
   全绿才组装。
2. **组装器合并 tr 目录下全部 `*.txt`**：多文件同批时必须每文件独立 tr 目录
   （B2 实测 ffplay/ffprobe 同目录时索引互相污染报 extra error）；
   utils 用同目录分块（块内索引唯一即可）。
3. **代码块段不能出现在 tr 文件**（空块也算）：组装器按 extra 报错；
   代码块一律由组装器从源逐字取用。
4. **B1 §5.2 预警的锚点桥接问题在 B2 提前成立并已解决**（DR-011）：
   翻译含被入链引用标题的页面（如 common-options 的 Stream specifiers）前，
   无需特殊操作——组装后 canonical 构建自动经 heading-bridge 重写；
   后续批次翻译新页时，若该页标题被站内入链以英文锚点引用，
   **随批在 config/heading-bridge.yml 登记**（键=入链书写形式）。
5. **ffprobe 输出 section 依 glossary 译作"小节"**（术语表 section=小节），
   writer 译作"写入器"（首次出现括注），均随批补录进 glossary；
   后续批遇新术语沿用"随批补录"约定。
6. **Mimosa 钩子两类误拦**：①命令字符串同时含 `mv/mkdir` 与 scripts/*.py
   路径字样会误判"直接写源码"（拆开命令即可）；②tests/scripts 文件追加
   必须走 Write/Edit（cat >> 被拦）。tr/交接等非源码 /tmp 文件不受限。
7. **fix_links 构建期回写不入库**：zh/ 页在 canonical 构建后被回写
   （英文锚→桥接目标），提交保持组装原样（B1 口径延续）；
   每次构建后 `git checkout -- zh/manual/ffmpeg.md zh/manual/ffplay.md`
   还原（common-options/utils 自身无入链不受影响）。
